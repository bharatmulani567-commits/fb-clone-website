# 📘 Facebook Clone Website

A simple Facebook website clone built using **HTML** and **CSS**. This project was created during a Git and GitHub tutorial to practice version control, repository management, and front-end web development fundamentals.

## 📖 About the Project

This project is a static clone of the Facebook landing page. It was developed as part of my learning journey to gain hands-on experience with HTML, CSS, and Git. The primary goal was to understand how to create a structured web page while also learning how to manage a project using Git and GitHub.

While working on this project, I learned how to initialize a Git repository, track changes, create commits, and push a project to GitHub. At the same time, I practiced building a responsive and visually appealing web page by recreating the layout of a well-known social media platform.

Although this project is a simple clone and does not include backend functionality or user authentication, it helped me strengthen my understanding of front-end development and version control.

## 💻 Getting Started

To run this project on your local machine:

1. Clone the repository:

```bash
git clone https://github.com/your-username/fb-clone-website.git
```

2. Navigate to the project directory:

```bash
cd fb-clone-website
```

3. Open the `index.html` file in your preferred web browser.
